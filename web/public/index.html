Overview

GeneSynonym Resolver turns the many names a gene goes by into one official NCBI Gene record. It is built for species that the usual conversion tools handle poorly.

The problem

The same gene is often written in several ways: an official symbol, older synonyms, a locus tag, a name borrowed from the human or mouse equivalent. In well-studied species the databases agree on these names. In non-model species they frequently do not. One name can point to two genes, two names can point to one gene, and identifiers get retired or merged between releases.

This tool does not guess. It lists every gene a name could mean, ranks them by how the name matched, and says plainly when the evidence is not enough to choose.

How a name is resolved

  1. Clean the name. Capitals, hyphens, underscores and extra spaces are normalised, and Greek letters are spelled out. The original text is always kept.
  2. Find every candidate gene. The cleaned name is compared with all stored names for the chosen species, or for every species.
  3. Assign a match tier. Each candidate is labelled by how closely the input matched (see the table below).
  4. Score and flag. Each candidate gets a confidence score. Ties, shared names and retired symbols are flagged instead of being hidden.

Match tiers

TierRuleExample
1The input is exactly the official gene symbol.TP53 → human TP53
2The input is exactly a stored synonym, alias or locus tag.P53 → human TP53
3The input matches only after capitals, hyphens, underscores and spacing are ignored.Tp53 → human TP53

Tier 2 only appears when you type an alias exactly as NCBI stores it. If you type an official symbol with different capitals, it is Tier 3, because the text is not an exact match. Cross-reference matches (tier 4) and fuzzy matches (tier 5) are planned. Fuzzy matches will never be accepted automatically.

Reading the confidence score

The confidence score is a number from 0 to 100% shown with every result. It combines two things.

Match typeHow reliable this kind of match is on its own: exact official symbol 98%, exact alias or locus tag 90%, official name with different capitals 92%, other cleaned matches 80%. Retired symbols are reduced by a quarter.
CompetitionThe score is shared with other genes that use the same name. A name that belongs to only one gene keeps its full score; a name shared by several genes splits it.
High · 85% or more Medium · 60 to 84% Low · below 60%

This is a transparent rule-based score, not yet a trained model, and it has not been calibrated against a benchmark set. Treat it as a guide to how much to double-check a result.

Using context

In the Bulk converter you can paste a few words about your experiment. When a name belongs to several genes equally, the words are compared with each gene's description. If one gene matches more of them, it is selected and its confidence rises. If the context does not separate the genes, nothing is guessed and the name stays ambiguous.

Flags you may see

No matchNo gene in the chosen species has this name, even after cleaning.
One name, many genesMore than one gene uses this name. All candidates are listed as alternatives.
Retired symbolThe name matched a symbol that is no longer current for the gene.
Resolved by contextSeveral genes share the name at the same level, and the optional context you gave in the Bulk converter matched only one of them.

If you enter a numeric Gene ID that NCBI has replaced or merged, the tool follows the change and shows the current gene.

Data sources

Names, synonyms, locus tags, descriptions and retired identifiers come from the NCBI Gene files gene_info and gene_history. Species names follow NCBI Taxonomy.

What it does not do yet

Orthology across model species, synteny and protein-domain evidence, and a trained ranking model are part of the project plan but are not in this version. Results here rest on name matching against NCBI Gene.
